---
name: "Agent File Content Standards"
description: "Keep agent markdown files short, plain English, and under 50 lines of body content."
applyTo: "**/AGENTS.md"
---

Agent files must be short, plain English descriptions under 50 lines of body content (excluding frontmatter).

- Write in plain English. Describe what the agent does and when to use it — nothing more.
- Do not include YAML snippets, terminal commands, or code blocks.
- Do not list files or directory contents.
- Do not paste file content, config extracts, or log output.
- Do not include exhaustive bullet lists of trigger phrases or routing rules.
